Per D-09 contract (RESEARCH Code Example, lines 386-392) and UI-SPEC §Editing Chrome (Numeric cell contract, line 219):
- Props: { valueMinor: number, currency: string, onCommit: (valueMinor: number) => void, onCancel: () => void }
- Render: contentEditable div with inputMode="decimal"
- Keystroke filter: onKeyDown interceptor — allow digits (0-9), ONE decimal separator (.,), ONE leading minus (-), Backspace/Delete/Tab/Enter/Escape/arrows. All other keys: e.preventDefault().
- Display: convert minor→major for display text: (valueMinor / 10^dec).toString(), where dec = CURRENCY_DECIMALS[currency]
- Commit path (blur/Enter): parse raw text → const dec = CURRENCY_DECIMALS[currency]; if (!isNaN(Number(raw))) { const minor = Math.round(Number(raw) * Math.pow(10, dec)); onCommit(minor) }
- Invalid: if NaN or parsing fails → show destructive ring (1.5px --destructive) + popover "Enter a valid number."
- Escape: cancel → call onCancel (restore prior model value)
- Tab/Shift+Tab: commit + move focus to next/previous cell (by setting tabIndex on sibling cells and calling focus())
- Format display: existing formatMinor() from DocumentPage.tsx:35-37 for the view mode display (EUR Intl.NumberFormat). Edit mode: show raw decimal string (not currency-formatted) for natural number input.
- NEVER use bare floats — all commit paths route through money.ts roundMinor (Phase-2 locked contract)
- The initial render shows the formatted value in view mode; on focus, switch to raw decimal string for editing.

|----------|-------------|
| Numeric input→money.ts | User-entered decimal string converted to minor units — must route through roundMinor, never bare floats |
| File input→lineItem.image | FileReader reads local file as data:-URL — no external fetches, no cross-origin |
| Clipboard→delete confirm | Delete action on line items — confirmation prevents accidental data loss |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-14 | Tampering | NumericCell float conversion | high | mitigate | All commit paths route through money.ts CURRENCY_DECIMALS + roundMinor. Bare floats prohibited. Invalid input → commit blocked + popover. Schema validates z.int().nonnegative() at boundary. |
| T-04-15 | Information disclosure | lineItem.image external URL | high | mitigate | File input only — FileReader produces data:-URLs naturally. Schema refine (logoSchema pattern from Plan 04-01) rejects external http(s) URLs at Zod boundary. No fetch involved. |
