=== ZOOM (BUIL-09) ===
Per D-24 ("canvas zoom is desktop-only") and UI-SPEC §overflow (zoom controls):

Zoom wrapper:
- Wrap the DocumentPage canvas container in a div with CSS transform: scale(zoomLevel)
- Zoom state: useState<number>(1). Bounds: min 0.5, max 2.0, step 0.1 (UI-SPEC: min/max bounds, buttons disabled at bounds).
- Transform origin: top center (so the page stays centered and scrolls from the top)
- The canvas container must adjust its size to prevent clipping: set width/height proportional to inverse scale (or use a container with overflow: auto).
- Print safety: the zoom wrapper carries a print:scale-100 Tailwind variant (or explicit @media print { transform: none !important }) so #print-root geometry is untouched in print/PDF. Print.css already hides builder chrome — the zoom reset is an additional guarantee.

Zoom controls (desktop only — hidden on <1024px):
- Header: zoom slider or +/- buttons + percentage readout (UI-SPEC §Component Inventory: "plain Button + Select or percent readout")
- "+" button (ZoomIn from lucide), "-" button (ZoomOut from lucide), percentage display "100%"
- Disabled state at min (50%) and max (200%) bounds per UI-SPEC §UI Considerations (overflow row)

=== PARITY EXTENSION ===
- Print with zoom: capture #print-root while zoom is active — assert the golden matches (proves zoom transform doesn't affect print projection).
- Already covered by existing structural checks — add a specific assertion: transform property on #print-root's closest shell ancestor must be 'none' in print media (window.getComputedStyle in print matchMedia).
</read_first>
