## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dialog state → rendered page stack | The measure-and-slice stack renders the same document N times — any layout side-effect would multiply across blocks |
| page size selection → print/PDF | The pageSize value crosses into @page selection and page.pdf() format |
| window.print() | The browser print pipeline prints the real document (no user input crosses here — print dialog is browser-owned) |
