## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local file → logo data: URL | User-selected image file crosses into the document model and renders in the DOM |
| branding object → renderer | Per-document branding values (colors, font ids, watermark override) flow into CSS vars and overlay markup |
| fixture content → harness | English fixture text feeds the golden-image comparisons |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02 | DoS | logo file input → readAsDataURL | medium | mitigate | Type allowlist (image/png, image/jpeg, image/svg+xml) + size gate ≤ 2 MB enforced at READ time, before FileReader; rejected file → inline error, no state change (UI-SPEC error copy). Source image never laid out at natural size (48px chip CSS object-fit). |
| T-03-01 | Tampering | logo img render | medium | mitigate | SVG-in-img is script-inert; schema refine keeps logo data: URL only (types.ts logoSchema) — the upload path produces data: URLs by construction (readAsDataURL), never remote URLs. |
| T-03-04 | Tampering | branding values → style/markup | high | mitigate | Branding strings (font ids, style ids, watermark enum) are zod-enum-constrained at the schema boundary; colors render as CSS values, never markup; document content remains React text nodes (grep-enforced). Watermark override is an enum, not free text. |
| T-03-05 | Info disclosure | print/PDF output | low | accept | Same as plan 01 — watermark is aria-hidden decoration; first-page-only limitation documented in ADR 0002, unchanged. |
| T-03-07 | Tampering | UPDATE_BASELINES golden writes | high | mitigate | UPDATE_BASELINES=1 is local-only (CI never sets it — workflow unchanged, verified in Task 3); the write path is gated behind a blocking-human review checkpoint (Task 3) before commit; blank/wrong-size guards run on every commit (width 794 + nonWhiteFraction). |
</threat_model>
